# 首页动态问候与巡检提示

## 目标

让首页问候语和引导文案根据当前时间及巡检状态变化，给出下一步最合适的操作提示。

## 规则

- 05:00–11:59 显示“上午好”；12:00–17:59 显示“下午好”；其余时间显示“晚上好”。
- 存在首页可继续的运行中任务时，显示“你有一项巡检正在进行，继续完成它吧”。
- 没有运行中任务、但存在最近巡检时，显示“上次巡检已完成，开始新的巡检吧”。
- 没有任何巡检记录时，显示“准备开始今天的巡检吧”。
- 文案只依赖现有 `homeResumeRun` 与 `homeRecentRun` 状态；不增加网络请求、后端字段或持久化数据。

## 验证

- 在三个时间段确认问候语正确。
- 分别验证运行中、仅有历史和无记录三种首页状态的引导文案。
- 首页“继续巡检”和“最近巡检”现有点击行为不改变。
